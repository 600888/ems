    #DLT698 动态库接入

    DL/T 698.45 复用现有 ABI v1（10 个 C 导出）、PluginManager 懒加载、统一 Handler 和 ChannelThread。协议名为 DLT698，运行时 model::ProtocolType::DLT698=8，保留已有编号。 默认加载 proto_dlt698.dll / libproto_dlt698.so；安装包为 plugins/dlt698/1.0.0/。

    #客户端配置

    {
  "protocol": "DLT698",
  "role": "client",
  "transport": "tcp",
  "connection": "127.0.0.1:6980",
  "meter_address": "123456789012",
  "logical_address": 0,
  "client_address": 0,
  "timeout_ms": 5000,
  "connection_profile": "remote_public",
  "points": [
    {"code": "voltage_a", "oad": "2000/2/1"},
    {"code": "threshold", "oad": "F001/2/0", "type": "int16"}
  ],
  "allow_writes": false
}

    顶层参数优先于 settings；settings 支持对象或 JSON 对象字符串。ip（或 host）和 port 也可指定端点。connection 存在时使用其主机，显式 port 优先于 connection 内端口。 默认客户端 127.0.0.1:6980、服务端 0.0.0.0:6980；IPv6 使用 [::1]:6980。 timeout_ms 为 1..600000 毫秒，优先于旧 timeout（1..600 秒），覆盖建连、登录及请求。

    remote_public 先由协议服务器发送 LINK 登录，再 CONNECT；local_public 直接公共 CONNECT，适用于本地电表。两端须采用相同场景。服务端 heartbeat_seconds 默认 5， 零关闭；max_connections 默认 16。自动重连沿用采集通道现有逻辑。

    表地址兼容 rtu_addr，1..12 位十进制左补零到 12 位，更长须为偶数位，最多 32 位。 按 BCD 低字节在前编码，例如 123456789012 在线序为 12 90 78 56 34 12。 逻辑地址范围 0..3，客户端地址范围 0..255，两端须一致。

    串口使用 transport=rtu（或 serial）、serial_port=COM3（或 connection）， 默认 9600/8E1 和 local_public。支持 baud_rate/baudrate、data_bits/databits、 stop_bits/stopbits，parity 为 even/odd/none 或 E/O/N，启用 FE 前导及帧间隔适配。

    #测点与读写

    编码支持 2000/2/1（OI 为十六进制，属性与索引为十进制）、20000201 / 0x20000201（完整四字节 OAD 十六进制文本），以及配置的 code 别名。 配置的数值型 oad 按 uint32 解释。索引零读取完整属性，非零索引从 1 开始。 点位系数、偏移和工程单位由上层点映射处理，不在插件中重复换算。

    批量读取按最多 32 个属性拆分 GET NormalList，保留输入顺序。有限标量返回 quality=0， 坏地址、DAR、非数值及通信错误逐点返回 value=null、quality=1，函数返回有效点数。 附带 oad、data_type、含类型标签的 A-XDR data_hex、毫秒时间戳；拒绝读取时保留 dar。 数组/结构可用 OAD 元素索引读取标量。int64/uint64 超出 ±(2^53−1) 的值只保留原始编码。

    客户端 SET 须显式开启 allow_writes，并为目标 OAD 配置 type。支持 bool/boolean、 int8/16/32/64、uint8/16/32/64、enum、float32/64。整数无小数且不越界，布尔限 0/1， 所有值须有限。SET 不重试；DAR 非零失败并保留诊断。实际可写权限由电表决定。

    #只读上送

    {
  "protocol": "DLT698",
  "role": "server_readonly",
  "ip": "127.0.0.1",
  "port": 6980,
  "points": [
    {"code": "power", "oad": "F001/2/0", "type": "float64", "value": 12.5},
    {"oad": "F002/2/0", "data_hex": "01021208981208FC"},
    {"code": "phase_a", "oad": "F002/2/1", "type": "uint16"}
  ]
}

    role=server 和通道 local_role=server 同样表示只读上送。标准 OI 遵守库的精确类型及 数组布局，自定义 OI 声明只读 schema。data_hex 可初始化完整复合值，上例为两个 uint16（2200、2300）。带初值条目须为特征零、索引零的完整属性，且不能重复。 无初值条目定义别名及本地更新类型，可指向已发布元素。本地 write 更新映像，远端 SET/ACTION 拒绝。disconnect/connect 保留映像；成功重新 initialize 替换映像。

    #构建与验证

    cmake -S backend/src/net/handler -B build/dlt698 -G Ninja `
  -DEMS_BUILD_MODBUS=OFF -DEMS_BUILD_IEC104=OFF -DEMS_BUILD_DLT645=OFF
cmake --build build/dlt698 --parallel 3
ctest --test-dir build/dlt698 --output-on-failure
cmake --install build/dlt698 --prefix build/dlt698-package

    需要 C++17、CMake 3.15+；协议栈及 Asio 静态编入插件。第三方源码保持原样，构建目录 的托管层副本使用集成层回收器，在最后一个协议实例销毁时先结束线程，避免 Windows DLL 卸载期间的 loader lock 死锁。

    测试覆盖动态加载/卸载、配置校验、独立第三方服务端 GET/SET、复合值/大整数/坏点、 跨块批次、只读上送、本地更新、重连、ABI 缓冲区重试及 Handler。串口硬件、RS-485 方向时序和真实电表仍需现场联调。记录选择器、ACTION、PROXY 和 ESAM 认证暂未映射到 当前统一数值点接口。
