# 架构与业务模型

这里定义跨进程共享的系统边界和业务对象，先确定模型，再阅读各进程实现设计。

1. [EMS 系统架构](system-design.md)：五类业务进程、数据职责、控制闭环、部署与实施阶段。
2. [设备模型与点表绑定](device-model.md)：实际设备、固有点位、厂家差异、标准转换、启用与控制反馈。
3. [设备、通道与协议](channel-protocol.md)：设备/通道多对多绑定，采集/上送用途，协议角色、资源、会话和地址映射。

设备身份独立于通信路径；通道用途独立于客户端/服务端角色；工业协议通道与 Redis/共享内存等内部数据访问后端是不同层。运行时分工见 [进程设计](../processes/index.md)，共享技术契约见 [公共模块](../common/index.md)。
