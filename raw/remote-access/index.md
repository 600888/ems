# 远程接入

集中记录 EMS 异地联调与设备运维的接入方法，按使用场景选择工具。

| 工具 | 适用场景 | 文档 |
| --- | --- | --- |
| OpenVPN | 多台主机通过虚拟 IP 互访，访问 SSH、Web 等服务 | [服务端部署](openvpn/server.md) · [客户端部署](openvpn/client.md) |
| Frp | 将指定的内网端口映射到公网入口 | [待补充](frp.md) |
| 向日葵 | 远程桌面、人工协助与图形界面运维 | [待补充](sunlogin.md) |

批量准备客户端部署包时，见 [OpenVPN 脚本生成客户端配置与部署](openvpn/client-package.md)。

首次搭建 OpenVPN，先完成服务端，再为每台客户端分别签发证书。文中每条操作命令独立展示，
说明执行位置、目的与预期结果，可通过右上角的“复制代码”逐条复制。
完整配置单独成块，粘贴到指定文件；原文截图放在对应步骤旁供对照。
