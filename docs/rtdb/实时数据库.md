# EMS实时数据库 (RTDB)

基于Redis的实时数据库模块，用于储能EMS系统。

## 特性

- Redis连接管理
- 实时数据点存储（带时间戳和质量）
- Hash数据操作
- 字符串操作
- 键值管理
- 发布/订阅支持
- 线程安全
- 自动重连

## 依赖

- hiredis (Redis C客户端)
- C++11 或更高版本

## 安装依赖

```bash
# Ubuntu/Debian
sudo apt-get install libhiredis-dev

# CentOS/RHEL
sudo yum install hiredis-devel

# 或者从源码编译
git clone https://github.com/redis/hiredis.git
cd hiredis
make
sudo make install
```

## 构建

```bash
cd backend
mkdir build && cd build
cmake ..
make
```

## 使用示例

```cpp
#include "rtdb.h"
#include <memory>

int main() {
    ems::net::RTDBConfig config;
    config.host = "localhost";
    config.port = 6379;
    config.password = "";
    config.db = 0;
    config.pool_size = 10;
    config.timeout_ms = 5000;
    config.prefix = "ems:";

    auto rtdb = ems::net::createRTDB(config);
    if (!rtdb) {
        return 1;
    }

    // 存储字符串
    rtdb->set("key", "value");

    // 存储数据点（带时间戳和质量）
    rtdb->setDataPoint("sensor/temperature", "25.5", 0);

    // 读取数据点
    ems::net::DataPoint point;
    rtdb->getDataPoint("sensor/temperature", point);

    // Hash操作
    std::map<std::string, std::string> fields = {
        {"field1", "value1"},
        {"field2", "value2"}
    };
    rtdb->setHash("hash_key", fields);

    // 查询多个数据点
    auto points = rtdb->getDataPoints("sensor/*");

    rtdb->shutdown();
    return 0;
}
```

## API文档

### 基础操作

- `set(key, value)` - 设置字符串值
- `get(key, value)` - 获取字符串值
- `deleteKey(key)` - 删除键
- `exists(key)` - 检查键是否存在
- `keys(pattern)` - 获取匹配模式的键列表

### 数据点操作

- `setDataPoint(key, value, quality)` - 存储带时间戳的数据点
- `getDataPoint(key, point)` - 获取数据点
- `getDataPoints(pattern)` - 获取匹配模式的所有数据点

### Hash操作

- `setHash(key, fields)` - 设置Hash字段
- `getHash(key, fields)` - 获取Hash所有字段
- `setHashField(key, field, value)` - 设置Hash单个字段

### 高级操作

- `setWithExpire(key, value, seconds)` - 设置带过期时间的值
- `expire(key, seconds)` - 设置键过期时间
- `incr(key, result)` - 递增整数
- `incrByFloat(key, value, result)` - 递增浮点数
- `append(key, value)` - 追加字符串
- `publish(channel, message)` - 发布消息

### 配置

```cpp
struct RTDBConfig {
    std::string host;        // Redis服务器地址，默认localhost
    int port;                // Redis端口，默认6379
    std::string password;    // 密码（可选）
    int db;                  // 数据库编号，默认0
    int pool_size;           // 连接池大小，默认10
    int timeout_ms;          // 超时时间（毫秒），默认5000
    std::string prefix;      // 键前缀，默认""
};
```
